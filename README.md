# مربی‌یار | مدیریت برنامه تمرینی باشگاه

اپلیکیشن موبایلی فارسی و راست‌چین برای مدیریت ورزشکاران و برنامه‌های تمرینی مربی بدنسازی.

## امکانات نسخه پروژه
- ورود و مدیریت فقط با **رمز اصلی مربی**
- ثبت نام، سن و توضیحات ورزشکار
- بانک داخلی حرکات بدنسازی (دیتابیس محلی نمونه)
- جستجو و دسته‌بندی حرکات بر اساس عضله
- کارت آموزشی برای هر حرکت: عضله هدف، تجهیزات و نکته اجرای صحیح
- ساخت برنامه اختصاصی برای هر ورزشکار
- تعیین **تعداد تکرار و تعداد ست** برای هر حرکت
- نمایش خلاصه برنامه به‌صورت شماره‌گذاری‌شده
- ذخیره اطلاعات روی خود گوشی با SharedPreferences
- تولید گزارش متنی فارسی و اشتراک‌گذاری آن برای ورزشکار
- ورزشکار برای این مدل استفاده نیازی به نصب اپ ندارد
- اشتراک نمونه ۳۰ روزه و قفل شدن برنامه پس از پایان مدت
- فعال‌سازی مجدد ۳۰ روزه با رمز اصلی مربی
- تغییر رمز اصلی مربی
- رابط کاربری فارسی، راست‌چین و مناسب موبایل
- کاملاً Local و بدون نیاز عادی به سرور یا اینترنت هنگام استفاده

## نکته مهم درباره اشتراک
برای نمونه دانشگاهی، تاریخ فعال‌سازی روی خود دستگاه ذخیره می‌شود و بعد از ۳۰ روز دسترسی به برنامه قفل می‌شود. با وارد کردن رمز اصلی در صفحه قفل، یک دوره ۳۰ روزه جدید فعال می‌شود. این قسمت **شبیه‌سازی اشتراک** است و برای محصول تجاری واقعی باید به سیستم پرداخت و اعتبارسنجی امن سمت سرور متصل شود.

## ساخت APK بدون نصب Flutter روی ویندوز
این پروژه یک GitHub Action آماده دارد:

1. پروژه را در یک Repository گیت‌هاب قرار دهید.
2. وارد تب **Actions** شوید.
3. Workflow با نام **Build Android APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. پس از پایان موفق، از بخش **Artifacts** فایل `morabi-yar-release-apk` را دریافت کنید.

Workflow خودش Flutter و فایل‌های Android را آماده می‌کند و سپس APK Release می‌سازد.

## ساخت محلی در صورت نصب Flutter
```bash
flutter pub get
flutter build apk --release
```

APK خروجی:
`build/app/outputs/flutter-apk/app-release.apk`
